# Pool Sinonim / Parafrase JLPT N5 (言い換え類義)

Sumber soal **`MG-ruigi`** di skill `/jlpt` (Sesi 1 文字・語彙). Di JLPT N5, tipe
言い換え類義 memberi satu kalimat, lalu meminta memilih kalimat/kata yang **artinya
paling dekat**. File ini mengumpulkan pasangan parafrase N5 yang lazim. **Boleh
ditambah bertahap** (seperti `n5-vocabulary.md`).

> Tulisan soal: hiragana + kanji umum N5; **setiap kanji diberi bacaan hiragana**
> (mis. 大学（だいがく）). Distraktor sebaiknya kata yang mirip topik tapi arti beda.

## Pasangan kata ⇄ padanan
| Kata / frasa | ≈ Padanan terdekat | Catatan |
|--------------|--------------------|---------|
| つまらない | おもしろくない | "tidak menarik" |
| まずい | おいしくない | "tidak enak" |
| たいへん | とても / すごく | penekanan "sangat" |
| おおぜい | ひと が たくさん | "banyak orang" |
| きれい（な へや） | そうじ して ある | "rapi/bersih" ⇄ "sudah dibersihkan" |
| ひま（な） | しごと／じかん が ない いそがしくない | "luang" |
| だいじょうぶ | もんだい ない | "tidak apa-apa" |
| ちかい | とおくない | "dekat" ⇄ "tidak jauh" |
| やさしい（もんだい） | かんたん（な） | "mudah" |
| むずかしい | やさしくない / かんたんじゃない | "sulit" |
| ゆうめい（な） | みんな しって いる | "terkenal" |
| びょうき | げんき じゃ ない | "sakit" ⇄ "tidak sehat" |

## Pasangan frasa/kalimat ⇄ parafrase
| Kalimat | ≈ Parafrase terdekat | Catatan |
|---------|----------------------|---------|
| A は B より たかい | B は A より やすい | pembalikan perbandingan (L12) |
| まいにち べんきょう します | やすみ の ひ も べんきょう します | "tiap hari" ⇄ "libur pun belajar" |
| りょうしん | ちち と はは | "orang tua" = ayah + ibu |
| きょうだい | あに や おとうと | "saudara" |
| もう ごはん を たべました | もう おなか が すいて いません | "sudah makan" ⇄ "sudah tidak lapar" |
| この みせ は やすい | この みせ は ねだん が たかくない | "murah" ⇄ "harga tidak mahal" |
