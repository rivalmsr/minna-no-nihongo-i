# 第2課 — 練習A (Lesson 2 — Practice A)

**Topik:** Kata penunjuk benda (これ / それ / あれ dan この / その / あの) serta
partikel **の**.

> Ringkasan cepat:
> - **これ・それ・あれ** = kata tunjuk yang **berdiri sendiri** (bisa langsung + partikel は).
> - **この・その・あの** = kata tunjuk yang **harus menempel pada kata benda** (この + benda + は).
> - **の** = partikel penghubung antar kata benda (menerangkan / kepemilikan).

Jarak pembicara:
| Dekat pembicara | Dekat lawan bicara | Jauh dari keduanya |
|-----------------|--------------------|--------------------|
| これ / この (ini) | それ / その (itu) | あれ / あの (itu, di sana) |

---

## Pola 1 — Kata tunjuk これ / それ / あれ + partikel は

Kata tunjuk ini bisa **langsung diikuti** partikel **は**.

**Rumus:** `これ/それ/あれ + は + [benda] + です`

- これは とけい です。 → kalimat **positif** ("Ini adalah jam.")
- それは とけい ですか。 → kalimat **tanya** (tanpa kata tanya なん, jawabannya はい / いいえ)
  - …はい、これは とけい です。 → jawaban **positif**
  - …いいえ、これは とけいじゃ ありません。 → jawaban **negatif** (`~じゃ ありません`)
- それは なん ですか。 → kalimat tanya dengan kata tanya **なん** ("Itu apa?")
  - …これは とけい です。

**Catatan:**
- Negatif dari `です` adalah `じゃ ありません` (bentuk lisan/sopan).
- Pertanyaan **ya/tidak** → dijawab はい / いいえ.
- Pertanyaan dengan **なん** ("apa") → dijawab dengan nama bendanya.

---

## Pola 2 — Menegaskan pilihan (A ですか、B ですか)

Untuk memastikan kebenaran benda dengan menawarkan dua pilihan.

**Rumus:** `これ/それ/あれ + は + [A] + ですか、[B] + ですか`

- それは ボールペン ですか、シャープペンシル ですか。
  - …これは シャープペンシル です。

**Catatan:** Jawabannya **memilih salah satu**, bukan はい / いいえ.

---

## Pola 3 — Partikel の untuk menerangkan (kategori/jenis)

Partikel **の** di sini **tidak punya arti**, tapi punya **fungsi**: menerangkan
sebuah kata benda dengan kata benda lain (misalnya jenis/topik).

**Rumus:** `[benda A] + の + [benda B]` → "B tentang/jenis A"

- これは コンピューターの ほんです。 → positif ("Ini buku (tentang) komputer.")
- それは なんの ほんですか。 → tanya ("Itu buku tentang apa?")
  - …これは にほんごの ほんです。 ("Ini buku bahasa Jepang.")

**Catatan:** `なんの + [benda]` = "[benda] tentang apa / jenis apa".

---

## Pola 4 — Partikel の untuk kepemilikan

Di sini partikel **の** berfungsi menyatakan **kepemilikan**.

**Rumus:** `[pemilik] + の + [benda]`

- これは わたしの ほんです。 → positif ("Ini buku saya.")
- これは わたしの ほんじゃ ありません。 → negatif ("Ini bukan buku saya.")
- あれは だれの ほんですか。 → tanya ("Itu buku siapa?")

**Catatan:** `だれの + [benda]` = "[benda] milik siapa".

---

## Pola 5 — Kepemilikan tanpa menyebut bendanya

Dipakai ketika pembicara & lawan bicara **sama-sama sudah paham** benda apa yang
dibicarakan, sehingga nama bendanya **tidak perlu disebut** (の berdiri sebagai
pengganti benda).

**Rumus:** `[pemilik] + の + です` (benda dihilangkan)

- あれは だれの ですか。 → tanya ("Itu punya siapa?")
  - …あれは わたしの です。 → milik saya, **atau**
  - …あれは サトウさんの です。 → milik orang lain (Pak/Bu Satō)

**Catatan:** `わたしの` = "punya saya"; の di akhir menggantikan kata benda.

---

## Pola 6 — Kata tunjuk この / その / あの + kata benda

Selain lebih **sopan**, kata tunjuk ini **harus menempel** pada kata benda —
**tidak bisa** langsung diikuti partikel は.

**Rumus:** `この/その/あの + [benda] + は + … + です`

- この ほんは わたしの です。 → positif
  - Di sini **「この ほん」** ("buku ini") menjadi subjek, baru diikuti partikel は.

**Catatan — perbedaan penting:**
| | Berdiri sendiri | Menempel ke benda |
|---|---|---|
| Dekat | これ | この + benda |
| Sedang | それ | その + benda |
| Jauh | あれ | あの + benda |

- ✅ これは ほんです。 / ✅ この ほんは わたしの です。
- ❌ この は … (この tidak boleh langsung + は)

---

## Catatan koreksi ejaan (dari catatan asli)

Beberapa kosakata pada catatan asli dirapikan ke ejaan katakana baku:
- ボウルペン → **ボールペン** (ballpoint pen)
- シャアぷペンシル / シャぷペンシル → **シャープペンシル** (mechanical pencil)
- サトさん → **サトウさん** (nama, jika dimaksud "Satō")

Silakan sesuaikan bila catatan aslimu memang berbeda.
