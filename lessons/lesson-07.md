# 第7課 — 練習A (Lesson 7 — Practice A)

**Topik:** Partikel **で** untuk **alat/media** ("menggunakan") & **bahasa**
("dalam bahasa …"), partikel **に** untuk **memberi/menerima**
(あげます・もらいます dsb.), dan **もう** ("sudah") untuk menanyakan aktivitas
yang selesai.

> Ringkasan cepat:
> - **で** = "menggunakan (alat)" atau "dalam (bahasa)".
> - **に** + あげます/かします/おしえます = "**kepada**" (memberi).
> - **に** + もらいます/かります/ならいます = "**dari**" (menerima).
> - **もう + [kata kerja lampau]** = "sudah …?"; jawab はい／いいえ、まだです.

Arah memberi ↔ menerima (siapa yang jadi patokan = **わたし**):
| Kata kerja | Arti | Fungsi に |
|------------|------|-----------|
| あげます / かします / おしえます | memberi / meminjami / mengajari | orang に = **kepada** |
| もらいます / かります / ならいます | menerima / meminjam / belajar-dari | orang に = **dari** |

---

## Pola 1 — Alat aktivitas (partikel で)

Partikel **で** menandai **alat** yang dipakai untuk melakukan aktivitas.

**Rumus:** `[subjek] + は + [alat] + で + [objek] + を + [kata kerja]`

- わたしは スプーンと フォークで ごはんを たべます。 → positif ("Saya makan nasi pakai sendok dan garpu.")
- あなたは なんで ごはんを たべますか。 → tanya ("Kamu makan nasi pakai apa?")
  - …はしで たべます。 → positif ("…pakai sumpit.")

**Catatan:**
- `なんで` = "dengan/pakai apa?".
- **で** ini = "alat" — bandingkan で transportasi ([Lesson 5](lesson-05.md)) &
  で tempat aktivitas ([Lesson 6](lesson-06.md)).

---

## Pola 2 — Media / cara (partikel で)

Formula sama dengan Pola 1. **で** juga dipakai untuk **media/cara** melakukan
sesuatu (mis. menulis dengan bahasa tertentu).

**Rumus:** `[subjek] + は + [media] + で + [objek] + を + [kata kerja]`

- わたしは にほんごで レポートを かきます。 → positif ("Saya menulis laporan dalam bahasa Jepang.")

**Catatan:** `かきます` = menulis; `レポート` = laporan.

---

## Pola 3 — Terjemahan antar bahasa (partikel で)

**で** di sini berarti **"dalam suatu bahasa"** — untuk menyatakan/ menanyakan
terjemahan.

**Rumus:** `[kata] + は + [bahasa] + で + [terjemahan] + です`

- 「ありがとう」は えいごで "Thank you" です。 → positif ("'Arigatō' dalam bahasa Inggris 'Thank you'.")
- 「ありがとう」は インドネシアごで なん ですか。 → tanya ("'Arigatō' dalam bahasa Indonesia apa?")
  - …"Terima kasih" です。 → positif.

**Catatan:** `なん ですか` menanyakan padanan katanya. `〜ご (〜語)` = "bahasa …".

---

## Pola 4 — Memberi: に = "kepada"

Partikel **に** menandai **penerima** ("kepada/untuk") saat memakai kata kerja
**あげます** (memberi), **かします** (meminjami), **おしえます** (mengajari).

**Rumus:** `[subjek] + は + [orang] + に + [objek] + を + あげます`

- わたしは さとうさんに チョコレートを あげます。 → positif ("Saya memberi cokelat kepada Pak Satō.")
- あなたは だれに チョコレートを あげますか。 → tanya ("Kamu memberi cokelat kepada siapa?")
  - …かのじょに あげます。 → positif ("…kepada pacar/dia (perempuan).")

**Catatan:** `だれに` = "kepada siapa?"; `かのじょ` = dia (perempuan) / pacar.

---

## Pola 5 — Menerima: に = "dari"

Formula sama dengan Pola 4, tapi dengan **もらいます** (menerima), **かります**
(meminjam), **ならいます** (belajar dari). Di sini **に** berarti **"dari"**.

**Rumus:** `[subjek] + は + [orang] + に + [objek] + を + もらいます`

- わたしは ワットさんに ほんを もらいました。 → positif lampau ("Saya menerima buku dari Pak Watt.")
- あなたは だれに ほんを もらいましたか。 → tanya lampau ("Kamu menerima buku dari siapa?")
  - …かいしゃの ひとに もらいました。 → positif lampau ("…dari orang perusahaan/rekan kerja.")

**Catatan:**
- Objek/kata kerja **sama** dengan Pola 4, yang berbeda hanya **arah**: memberi
  (Pola 4) vs menerima (Pola 5).
- `から` juga bisa menggantikan `に` untuk "dari" (mis. `ワットさんから`).
- `かいしゃの ひと` = "orang perusahaan" — pakai partikel の ([Lesson 2](lesson-02.md)).

---

## Pola 6 — もう ("sudah") untuk aktivitas selesai

**もう** = "sudah". Menanyakan apakah suatu aktivitas **sudah dilakukan**;
kata kerjanya berbentuk **lampau**.

**Rumus:** `もう + [objek]を/へ + [kata kerja lampau]か`

- もう にもつを おくりましたか。 → tanya lampau ("Apakah bagasi/paket sudah dikirim?")
  - …はい、もう おくりました。 → positif ("Ya, sudah dikirim.")
  - …いいえ、まだです。 → belum ("Belum.")

**Catatan:**
- Jawaban "belum" = **いいえ、まだです** (bukan `おくりませんでした`).
- `にもつ` = bagasi/paket; `おくります` = mengirim; `まだ` = belum.
