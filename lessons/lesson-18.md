# 第18課 — 練習A (Lesson 18 — Practice A)

**Topik:** Kata kerja **bentuk kamus (辞書形 / じしょけい)** — cara pembentukannya per
kelompok, lalu pola: menyatakan **kemampuan** dengan **〜ことが できます** / **N が
できます**, menyebut **hobi** dengan **しゅみ**, dan **〜まえに** ("sebelum …" / "… yang lalu").

> Ringkasan cepat:
> - **辞書形** = bentuk dasar kamus; **searti** dengan bentuk ます (かう = かいます).
> - **Kelompok I**: bunyi baris **い** sebelum ます → baris **う** (かいます → かう).
> - **Kelompok II**: ます → **る**. **Kelompok III**: きます→くる, します→する.
> - Kemampuan: **N が できます** atau **[辞書形]ことが できます**.
> - **しゅみは [N／辞書形こと] です**; **[辞書形／Nの／durasi] + まえに** = "sebelum / yang lalu".

---

## Fondasi — Pembentukan bentuk kamus (辞書形) per kelompok

### Kelompok I

Bunyi **い・ち・り・び・み・に・き・ぎ・し** sebelum ます (baris **い**) diganti ke
**baris う**:

| Bunyi (〜ます) | Jadi | Contoh |
|--------------|------|--------|
| い | う | かいます → かう |
| ち | つ | たちます → たつ |
| り | る | はいります → はいる |
| び | ぶ | よびます → よぶ |
| み | む | よみます → よむ |
| に | ぬ | しにます → しぬ |
| き | く | かきます → かく |
| ぎ | ぐ | およぎます → およぐ |
| し | す | はなします → はなす |

### Kelompok II

Ganti **ます → る**.

- たべます → たべる ・ おしえます → おしえる
- (yang berbunyi "i": かります, あびます, おきます, みます, います — tetap kelompok II)

### Kelompok III

- きます → **くる** ・ します → **する**
- Turunan …します: べんきょうします → べんきょうする

> Bentuk ます dan bentuk kamus **artinya sama**; yang beda hanya tingkat kesopanan/gaya.

---

## Pola 1 — Kemampuan (〜ことが できます / N が できます)

Menyatakan **bisa / mampu** melakukan sesuatu.

**Rumus:**
- Dengan kata benda: `[kata benda] が できます`
- Dengan kata kerja: `[辞書形] + こと + が できます`

- わたしは りょうりが できます。 → ("Saya bisa memasak.")
- わたしは にほんごで はなすことが できます。 → ("Saya bisa berbicara dalam bahasa Jepang.")
- ミラーさんは くるまの うんてんが できます。 → ("Miller-san bisa menyetir mobil.")
- ミラーさんは かんじを よむことが できます。 → ("Miller-san bisa membaca kanji.")

**Catatan:**
- **こと** mengubah kata kerja (辞書形) menjadi **kata benda** ("hal …-nya"), agar bisa
  dipasang **が できます**.

---

## Pola 2 — Kemampuan (lanjutan) & tanya-jawab

**Rumus:** `[辞書形] + ことが できます(か)`

- ここで きっぷを よやくすることが できます。 → ("Di sini bisa memesan tiket.")
- ここで おかねを かえることが できます。 → ("Di sini bisa menukar uang.")
- かんじを よむことが できますか。 → tanya ("Bisa membaca kanji?")
  - …はい、できます。 → ("Ya, bisa.")
- どんな がいこくごを はなすことが できますか。 → tanya ("Bahasa asing apa yang bisa Anda ucapkan?")
  - …えいごを はなすことが できます。 → ("Bisa berbahasa Inggris.")

---

## Pola 3 — Hobi (しゅみ)

**Rumus:**
- Hobi berupa **kata benda**: `しゅみは + [kata benda] + です`
- Hobi berupa **aktivitas**: `しゅみは + [辞書形] + こと + です`

- わたしの しゅみは スポーツ です。 → ("Hobi saya olahraga.")
- わたしの しゅみは サッカー です。 → ("Hobi saya sepak bola.")
- わたしの しゅみは ほんを よむこと です。 → ("Hobi saya membaca buku.")
- わたしの しゅみは どうぶつの しゃしんを とること です。 → ("Hobi saya memotret hewan.")

**Catatan:**
- Sama seperti Pola 1–2, aktivitas dijadikan benda dengan **辞書形 + こと**.

---

## Pola 4 — "Sebelum …" / "… yang lalu" (まえに)

**まえに** menyatakan **"sebelum"**; bila didahului **durasi waktu**, artinya
**"… yang lalu"**.

**Rumus:**
- `[辞書形] + まえに、…` (sebelum melakukan …)
- `[kata benda] + の + まえに、…` (sebelum …)
- `[durasi waktu] + まえに、…` (… yang lalu)

- ゲームを する まえに、べんきょうします。 → ("Sebelum main game, belajar dulu.")
- にほんへ くる まえに、にほんごを べんきょうしました。 → ("Sebelum datang ke Jepang, belajar bahasa Jepang.")
- かいぎの まえに、レポートを よまなければ なりません。 → ("Sebelum rapat, harus baca laporan.")
- しょくじの まえに、てを あらいます。 → ("Sebelum makan, cuci tangan.")
- いっしゅうかん まえに、あたらしい パソコンを かいました。 → ("Seminggu yang lalu, beli PC baru.")
- 60ねん まえに、にほんへ きました。 → ("60 tahun yang lalu, datang ke Jepang.")

**Catatan:**
- Kata kerja sebelum **まえに** selalu **辞書形** (bukan bentuk lampau), walau aksinya lampau.
- Kata benda memakai penghubung **の** (かいぎ**の** まえに), tetapi **durasi** tidak
  memakai の (いっしゅうかん まえに).
