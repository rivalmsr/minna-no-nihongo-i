# 第3課 — 練習A (Lesson 3 — Practice A)

**Topik:** Kata penunjuk **tempat** (ここ / そこ / あそこ dan bentuk sopan
こちら / そちら / あちら), menanyakan lokasi (どこ / どちら), asal usul, dan harga (いくら).

> Ringkasan cepat:
> - **ここ・そこ・あそこ** = kata tunjuk tempat ("di sini / di situ / di sana").
> - **こちら・そちら・あちら** = versi **lebih sopan**; juga dipakai untuk arah.
> - **どこ / どちら** = "di mana"; **どちら** lebih sopan & untuk asal/instansi.
> - **いくら** = "berapa (harga)".

Jarak pembicara:
| Dekat pembicara | Dekat lawan bicara | Jauh dari keduanya | Tanya |
|-----------------|--------------------|--------------------|-------|
| ここ / こちら | そこ / そちら | あそこ / あちら | どこ / どちら |

Hubungan dengan [Lesson 2](lesson-02.md):
| Benda (sendiri) | Benda (+ benda) | Tempat (sendiri) | Tempat (sopan) |
|---|---|---|---|
| これ・それ・あれ | この・その・あの | ここ・そこ・あそこ | こちら・そちら・あちら |

---

## Pola 1 — Kata tunjuk tempat sebagai subjek (ここ / そこ / あそこ)

Subjek kalimat adalah **kata tunjuk tempat**.

**Rumus:** `ここ/そこ/あそこ + は + [tempat] + です`

- ここは きょうしつ です。 → positif ("Di sini (adalah) ruang kelas.")

---

## Pola 2 — Nama tempat sebagai subjek

Subjek kalimat adalah **nama tempat**, kata tunjuk tempat jadi keterangannya.

**Rumus:** `[nama tempat] + は + ここ/そこ/あそこ + です`

- うけつけは ここ です。 → positif ("Resepsionisnya di sini.")
- うけつけは どこ ですか。 → tanya ("Resepsionisnya di mana?")

**Catatan:** `どこ` = kata tanya "di mana".

---

## Pola 3 — Nama orang sebagai subjek (menanyakan keberadaan)

Formula sama dengan Pola 2, tapi subjeknya **nama orang** (menanyakan orang itu ada di mana).

**Rumus:** `[nama orang] + は + [tempat] + です`

- さとうさんは じむしょ です。 → positif ("Pak/Bu Satō ada di kantor.")
- さとうさんは どこ ですか。 → tanya ("Pak/Bu Satō ada di mana?")

---

## Pola 4 — Bentuk sopan こちら / そちら / あちら

Formula sama dengan Pola 2 & 3, tapi memakai kata tunjuk tempat yang **lebih sopan**.
Kata tanyanya menjadi **どちら**.

**Rumus:** `[subjek] + は + こちら/そちら/あちら + です`

- エレベーターは こちら です。 → positif ("Liftnya di sebelah sini.")
- エレベーターは どちら ですか。 → tanya ("Liftnya di sebelah mana?")

**Catatan:** こちら／そちら／あちら／どちら lebih halus daripada ここ／そこ／あそこ／どこ.

---

## Pola 5 — どちら untuk menanyakan asal / instansi

Formula sama dengan Pola 3. **どちら** dipakai untuk menanyakan **asal negara,
universitas, tempat kerja**, dsb. secara sederhana & sopan.

**Rumus:** `[subjek: くに/だいがく/かいしゃ…] + は + どちら + ですか`

- くには どちら ですか。 → tanya ("Negara asal Anda mana?")
  - …くには インドネシア です。 → positif ("Negara saya Indonesia.")

**Catatan:** Jawaban `くには インドネシア です` lebih ringkas daripada
`わたしの くには インドネシア です` — konteksnya sudah jelas.

---

## Pola 6 — これ / それ / あれ + どこの (menanyakan asal barang)

Sama seperti kata tunjuk benda di [Lesson 2](lesson-02.md), dipakai menanyakan
**asal/pembuat** sebuah barang dengan `どこの` (dari mana / buatan mana).

**Rumus:** `これ/それ/あれ + は + どこの + [benda] + ですか`

- これは どこの くるま ですか。 → tanya ("Ini mobil buatan mana?")
  - …これは にほんの くるま です。 → positif ("Ini mobil (buatan) Jepang.")

**Catatan:** `どこの + [benda]` menggabungkan pola partikel の (Lesson 2) dengan
kata tanya tempat.

---

## Pola 7 — この / その / あの + benda + いくら (menanyakan harga)

Sama seperti この／その／あの di [Lesson 2](lesson-02.md) (harus menempel pada
kata benda), tapi dipakai untuk **menanyakan harga** dengan **いくら**.

**Rumus:** `この/その/あの + [benda] + は + いくら + ですか`

- この ネクタイは １，５００えん です。 → positif ("Dasi ini 1.500 yen.")
- この ネクタイは いくら ですか。 → tanya ("Dasi ini berapa harganya?")
  - …１，５００えん です。

**Catatan:**
- `いくら` = "berapa (harga)".
- `えん (円)` = yen. Angka dibaca: `１，５００ = せん ごひゃく`.

---

## Catatan koreksi ejaan (dari catatan asli)

- うけすけ → **うけつけ** (受付, resepsionis) — konsisten dengan baris positifnya.
- さんとさん → **さとうさん** (nama, "Satō").
