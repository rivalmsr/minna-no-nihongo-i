# 第14課 — 練習A (Lesson 14 — Practice A)

**Topik:** Kata kerja **bentuk 〜て (te-form)** — cara pembentukannya per kelompok
(I / II / III), lalu tiga pola yang memakainya: **〜て ください** (perintah/permintaan
sopan), **〜ましょうか** (menawarkan bantuan), dan **〜て います** (aktivitas yang
**sedang berlangsung**).

> Ringkasan cepat:
> - Bentuk **〜て** selalu berakhiran **て / で**; jadi fondasi banyak pola (perintah, izin, urutan aksi).
> - **Kelompok I** berubah menurut suku kata sebelum ます (い/ち/り→って, び/み/に→んで, き→いて, ぎ→いで, し→して); pengecualian **いきます→いって**.
> - **Kelompok II**: ます → **て** langsung (たべます → たべて).
> - **Kelompok III**: hanya **きます→きて** dan **します→して** (+ turunan …します).
> - **〜て ください** = "tolong …"; **〜ましょうか** = "mau saya …-kan?"; **〜て います** = "sedang …".

---

## Fondasi — Pembentukan bentuk 〜て per kelompok

Untuk mengubah **〜ます** → **〜て**, harus tahu dulu **kelompok** kata kerjanya.

### Kelompok I

Ciri: ada bunyi **い・ち・り・び・み・に・き・ぎ・し** tepat sebelum ます. Buang ます,
lalu ubah bunyi terakhir menurut tabel:

| Bunyi akhir (ます-stem) | Jadi | Contoh |
|------------------------|------|--------|
| い・ち・り | **って** | かいます → かって・まちます → まって・とります → とって |
| び・み・に | **んで** | よびます → よんで・のみます → のんで・しにます → しんで |
| き | **いて** | かきます → かいて |
| ぎ | **いで** | いそぎます → いそいで |
| し | **して** | かします → かして |

**Pengecualian:** **いきます → いって** (bukan いいて, walau berakhiran き).

### Kelompok II

Ciri: ada **vokal "e"** sebelum ます. Cukup ganti **ます → て**.

- たべます → たべて

**Pengecualian** (berbunyi "i" sebelum ます tapi tetap kelompok II): います, おきます,
あびます, かります, みます.

- います → いて ・ おきます → おきて ・ あびます → あびて ・ かります → かりて ・ みます → みて

### Kelompok III

Ciri: hanya **2** kata kerja dasar.

- きます → きて
- します → して
  - Perluasan …します ikut jadi …して: さんぽします → さんぽして.
  - Jika bagian します dibuang dan sisanya **bisa berdiri sebagai kata benda**
    (さんぽ, べんきょう), maka kata kerja itu **kelompok III**.

## Pola 1 — Perintah/permintaan sopan (〜て ください)

Kata kerja bentuk **〜て** + **ください** = "tolong (lakukan) …". Dipakai untuk
meminta atau mempersilakan dengan sopan.

**Rumus:** `[kata kerja: bentuk-て] + ください`

- もんだいを よんで ください。 → perintah ("Tolong baca soalnya.")
- こたえを かいて ください。 → perintah ("Tolong tulis jawabannya.")
- いそいで ください。 → perintah ("Tolong cepat / bergegaslah.")
- すみませんが、しおを とって ください。 → permintaan ("Maaf, tolong ambilkan garam.")
- すみませんが、でんわばんごうを おしえて ください。 → permintaan ("Maaf, tolong beri tahu nomor teleponnya.")
- どうぞ たくさん たべて ください。 → mempersilakan ("Silakan makan yang banyak.")
- どうぞ ゆっくり やすんで ください。 → mempersilakan ("Silakan istirahat dengan santai.")

**Catatan:**
- Partikel **が** setelah **すみません** **tak berarti** apa-apa; hanya membuat sambungan
  ke kalimat berikutnya terdengar **natural/halus**.
- **どうぞ** memberi nuansa **menawarkan/mempersilakan** orang lain melakukan sesuatu.

## Pola 2 — Menawarkan bantuan (〜ましょうか)

Kata kerja bentuk **〜ます** → **〜ましょうか** = "Mau saya …-kan? / Bagaimana kalau
saya …?". Dipakai saat **menawarkan diri** membantu.

**Rumus:** `[kata kerja: ます → ましょうか]`

- てつだいましょうか。 → tawaran ("Mau saya bantu?")
- まどを しめましょうか。 → tawaran ("Mau saya tutupkan jendelanya?")
- むかえに いきましょうか。 → tawaran ("Mau saya jemput?")

**Catatan:**
- よみます → よみましょうか ("Mau saya bacakan?"), とります → とりましょうか ("Mau saya ambilkan?").
- **むかえ** dari **むかえます** ("menjemput"): buang ます karena diikuti pola
  **〜に いきます** ([Lesson 13](lesson-13.md)) — "pergi untuk menjemput".

---

## Pola 3 — Aktivitas yang sedang berlangsung (〜て います)

Kata kerja bentuk **〜て** + **います** = aktivitas yang **sedang dilakukan sekarang**
(progresif). Sering dipasangkan dengan **いま** ("sekarang").

**Rumus:** `A は (いま) + [objek を] + [kata kerja: bentuk-て] + います`

- ミラーさんは いま レポートを よんで います。 → positif ("Miller-san sedang membaca laporan.")
- ミラーさんは いま テレビを みて います。 → positif ("Miller-san sedang menonton TV.")
- ミラーさんは いま にほんごを べんきょうして います。 → positif ("Miller-san sedang belajar bahasa Jepang.")
- ミラーさんは いま なにを して いますか。 → tanya ("Miller-san sekarang sedang melakukan apa?")

**Catatan:**
- **〜て います** di sini = **aksi berlangsung** ("sedang …").
- Bedakan dari **〜て います** di [Lesson 13](lesson-13.md) yang menyatakan **keadaan
  berlanjut** hasil aksi lampau (mis. けっこんして います = "sudah/berstatus menikah").
  Makna ditentukan oleh **jenis kata kerjanya** dan konteks.

---

## Catatan koreksi (dari catatan asli)

- **います "(bertemu)" → います "ada / berada"**: pada daftar pengecualian kelompok II,
  arti います yang benar adalah **"ada/berada (exist)"**, bukan "bertemu". Kata
  "bertemu" adalah **あいます** (kelompok I → **あって**, lihat [Lesson 6](lesson-06.md)).
