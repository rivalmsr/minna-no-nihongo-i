# 第17課 — 練習A (Lesson 17 — Practice A)

**Topik:** Kata kerja **bentuk ない (negatif pendek)** — cara pembentukannya per
kelompok, lalu empat pola: **〜ないで ください** (jangan …), **〜なければ なりません**
(harus …), **〜なくても いいです** (tidak perlu …), dan menjadikan objek **を → は**
sebagai topik kalimat.

> Ringkasan cepat:
> - **〜ない** = negatif pendek, **searti** dengan 〜ません (たべない = たべません).
> - **Kelompok I**: bunyi sebelum ます (baris う) → **baris あ** + ない (い → **わ**); pengecualian **あります → ない**.
> - **Kelompok II**: ます → **ない**. **Kelompok III**: きます→こない, します→しない.
> - **〜ないで ください** = "tolong jangan …"; **〜なければ なりません** = "harus …"; **〜なくても いいです** = "tidak perlu …".
> - Objek **を** bisa diangkat jadi **topik は** dan dipindah ke **awal** kalimat.

---

## Fondasi — Pembentukan bentuk ない per kelompok

### Kelompok I

Bunyi **い・ち・り・び・み・に・き・ぎ・し** sebelum ます (baris **う**) diganti ke
**baris あ**, lalu ます → **ない**:

| Bunyi (〜ます) | Jadi | Contoh |
|--------------|------|--------|
| い | **わ** | あいます → あわない (tidak bertemu) |
| ち | た | まちます → またない (tidak menunggu) |
| り | ら | とります → とらない (tidak mengambil) |
| び | ば | あそびます → あそばない (tidak bermain) |
| み | ま | よみます → よまない (tidak membaca) |
| に | な | しにます → しなない (tidak mati) |
| き | か | かきます → かかない (tidak menulis) |
| ぎ | が | いそぎます → いそがない (tidak buru-buru) |
| し | さ | はなします → はなさない (tidak bicara) |

- **Perhatikan**: い → **わ** (bukan あ), karena bunyi "wa".
- **Pengecualian**: **あります → ない** ("tidak ada"), **bukan** あらない.

### Kelompok II

Cukup ganti **ます → ない**.

- たべます → たべない ・ おしえます → おしえない ・ ねます → ねない
- (yang berbunyi "i": かります → かりない ・ あびます → あびない ・ みます → みない ・ います → いない)

### Kelompok III

- きます → **こない** ・ します → **しない**
- Turunan …します: べんきょうします → べんきょうしない ・ かいものします → かいものしない ・ さんぽします → さんぽしない

---

## Pola 1 — Larangan halus (〜ないで ください)

Bentuk **ない** + **で ください** = "tolong jangan …".

**Rumus:** `[kata kerja: bentuk-ない] + で ください`

- たばこを すわないで ください。 → perintah ("Tolong jangan merokok.")
- ここに はいらないで ください。 → perintah ("Tolong jangan masuk ke sini.")
- かさを わすれないで ください。 → perintah ("Tolong jangan lupa (bawa) payung.")
- しんぱいしないで ください。 → perintah ("Tolong jangan khawatir.")

**Catatan:**
- Contoh dasar: ドアを あけます → ドアを **あけないで** ください ("Tolong jangan buka pintu.").

---

## Pola 2 — Keharusan (〜なければ なりません)

Dari bentuk **ない**, buang **い** terakhir lalu tambah **ければ なりません** →
**〜なければ なりません** = "harus …".

**Rumus:** `[bentuk-ない: ない → なければ] + なりません`

- ほんを かえさなければ なりません。 → ("Harus mengembalikan buku.")
- くすりを のまなければ なりません。 → ("Harus minum obat.")
- ざんぎょうしなければ なりません。 → ("Harus lembur.")

**Catatan:**
- Berlaku semua kelompok: よみます → よま**なければ なりません**, たべます → たべ**なければ なりません**,
  べんきょうします → べんきょうし**なければ なりません**.

---

## Pola 3 — Tidak wajib (〜なくても いいです)

Dari bentuk **ない**, buang **い** terakhir lalu tambah **くても いいです** →
**〜なくても いいです** = "tidak perlu / tidak wajib …".

**Rumus:** `[bentuk-ない: ない → なくても] + いいです`

- なまえを かかなくても いいです。 → ("Tidak perlu menulis nama.")
- くつを ぬがなくても いいです。 → ("Tidak perlu melepas sepatu.")
- あした こなくても いいです。 → ("Besok tidak perlu datang.")

**Catatan:**
- よみます → よまない → **よまなくても** いいです; たべます → たべない → **たべなくても** いいです;
  べんきょうします → べんきょうしない → **べんきょうしなくても** いいです.

---

## Pola 4 — Objek を → topik は

Objek (**を**) bisa **diangkat jadi topik** dengan mengganti **を → は** dan
memindahkannya ke **awal** kalimat. **は** menandai topik (hal yang dibahas),
maka harus di depan.

**Rumus:** `[kata benda] は + … + [kata kerja]`

- レポートは あした かきます。 → positif ("Laporannya, ditulis besok.")
- しりょうは メールで おくって ください。 → perintah ("Dokumennya, tolong kirim lewat email.")
- コピーは まつもとさんに みせなければ なりません。 → ("Salinannya, harus diperlihatkan ke Matsumoto-san.")

**Catatan:**
- Bab ini sekadar **memperkenalkan** bahwa **を** bisa diganti **は** untuk menjadikan
  benda itu topik — tanpa syarat khusus.
- **を** = penanda objek; **は** = penanda topik (selalu di **awal** kalimat).

---

## Catatan koreksi ejaan (dari catatan asli)

- **ざんきょう → ざんぎょう** (残業 = "lembur"): ejaan yang benar ざん**ぎ**ょう
  (ざんぎょうします → ざんぎょうしなければ なりません).
- **よみない → よまない** (Pola 3/tidak-wajib): よみます kelompok I, bentuk ない-nya
  **よまない** (よみ → よま). Hasil akhir **よまなくても いいです** pada catatan asli
  sudah benar; hanya bentuk antaranya yang keliru tertulis よみない.
