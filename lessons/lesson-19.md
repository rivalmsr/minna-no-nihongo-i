# 第19課 — 練習A (Lesson 19 — Practice A)

**Topik:** Kata kerja **bentuk た (lampau pendek)** — cara pembentukannya per kelompok,
lalu pola: **〜たことが あります** (pernah …), **〜たり、〜たり します** (menyebut
beberapa aktivitas), dan **〜なります** (menjadi / berubah menjadi …).

> Ringkasan cepat:
> - **〜た** = lampau pendek; polanya **sama seperti bentuk て**, hanya て/で → **た/だ**.
> - **〜たことが あります** = "pernah …"; negatifnya **〜たことが ありません** ("tidak pernah").
> - **〜たり、〜たり します** = menyebut **beberapa** aktivitas (tak berurutan); yang dikonjugasi hanya **します** di akhir.
> - **なります** = "menjadi": な-adj / N + **に なります**; い-adj → **く なります**.

---

## Catatan kosakata (言葉)

### のぼります — に vs を

- **やまに のぼります** = "mendaki gunung" — pakai **に** karena やま jadi **tujuan** gerak.
- **かいだんを のぼります** = "naik tangga" — pakai **を** karena bergerak **melintasi
  permukaan** かいだん (dari satu anak tangga ke berikutnya, mis. lantai 1 → 2).

### Kata kerja lain

- **とまります (泊まります) I** = "menginap": ホテル**に** とまります (pakai **に**, sifatnya "stay/tinggal").
- **せんたくします (洗濯します) III** = "mencuci pakaian" — sudah bermakna "cuci baju",
  jadi **tak perlu** objek ふく.

---

## Fondasi — Pembentukan bentuk た per kelompok

Polanya **identik dengan bentuk て**, tinggal ganti **て → た** dan **で → だ**.

### Kelompok I

| Bunyi (〜ます) | Jadi | Contoh |
|--------------|------|--------|
| い・ち・り | **った** | かいます → かった・まちます → まった・はいります → はいった |
| び・み・に | **んだ** | あそびます → あそんだ・よみます → よんだ・しにます → しんだ |
| き | **いた** | かきます → かいた |
| ぎ | **いだ** | いそぎます → いそいだ |
| し | **した** | はなします → はなした |

- **Pengecualian**: **いきます → いった**.

### Kelompok II

Ganti **ます → た**.

- たべます → たべた ・ かえます → かえた
- (pengecualian bunyi "i": います → いた, おきます → おきた, あびます → あびた, かります → かりた, みます → みた)

### Kelompok III

- きます → **きた** ・ もってきます → もってきた
- します → **した** ・ べんきょうします → べんきょうした ・ かいものします → かいものした ・ さんぽします → さんぽした

---

## Pola 1 — Pengalaman "pernah" (〜たことが あります)

Bentuk **た** + **ことが あります** = "pernah …". Negatifnya **〜たことが ありません**
("tidak pernah").

**Rumus:** `[bentuk-た] + ことが あります／ありません`

- わたしは おきなわへ いったことが あります。 → ("Saya pernah pergi ke Okinawa.")
- わたしは ふじさんに のぼったことが あります。 → ("Saya pernah mendaki Gunung Fuji.")
- わたしは すしを たべたことが あります。 → ("Saya pernah makan sushi.")
- カラオケに いったことが ありますか。 → tanya ("Pernah pergi karaoke?")
  - …いいえ、ありません。 → ("Tidak, belum pernah.")
  - …はい、あります。 → ("Ya, pernah.")

**Catatan:**
- Beda dari lampau biasa (〜ました = "sudah/telah"), pola ini menyatakan **pengalaman**
  ("pernah/tidaknya").

---

## Pola 2 — Menyebut beberapa aktivitas (〜たり、〜たり します)

Menyebut **beberapa** (biasanya 2–3) dari sekian aktivitas, **tanpa urutan
kronologis**. Yang dikonjugasi (negatif/lampau/keharusan) hanya **します** di **akhir**.

**Rumus:** `[bentuk-た]り、[bentuk-た]り + します`

- まいばん テレビを みたり、ほんを よんだり します。 → positif
  ("Tiap malam (kadang) menonton TV, membaca buku, dsb.")
- きのうは そうじしたり、せんたくしたり しました。 → lampau
  ("Kemarin bersih-bersih, mencuci baju, dsb.")
- にちようびは そうじしたり、せんたくしたり しなければ なりません。 → + keharusan
  ("Hari Minggu harus bersih-bersih, mencuci, dsb.")

**Catatan:**
- Aktivitas yang disebut **tidak** harus berurutan (beda dari 〜て、〜て pada Lesson 16).
- Perubahan bentuk (negatif/lampau/harus) hanya di **します paling belakang**.

---

## Pola 3 — Perubahan "menjadi …" (なります)

Menyatakan **berubah menjadi** suatu keadaan/hal.

**Rumus:**
- **な-adj / kata benda** → tambah **に なります**
- **い-adj** → ubah **い → く なります**

- テレーザちゃんは せが たかく なりました。 → ("Teresa jadi (lebih) tinggi.")
- テレーザちゃんは げんきに なりました。 → ("Teresa jadi sehat/bugar.")
- テレーザちゃんは 10さいに なりました。 → ("Teresa jadi berumur 10 tahun.")

**Catatan:**
- Contoh lain: ゆうめい → ゆうめい**に** なります, いしゃ → いしゃ**に** なります,
  やすい → やす**く** なります.

---

## Catatan koreksi ejaan (dari catatan asli)

- **いしゃに あります → いしゃに なります**: "menjadi dokter" memakai **なります**
  (perubahan), bukan あります.
